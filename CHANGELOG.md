# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Entries for each release are auto-generated by the `/release` skill from
`git log <prev-tag>..HEAD` at release time. No `[Unreleased]` section is
maintained — commits land on `main` and get grouped into the next release's
entry when the tag is cut.

## [3.0.27] - 2026-10-08

Agents in a room bound to two herdr workspaces stay in it, the old background daemon's job is cleaned up, and a task's Discussion looks the same wherever you open it.

### Fixed
- **Agents no longer drop out of a room and rejoin every few seconds** when the room is bound to two herdr workspaces. Each workspace's sync retired the other one's agents as if their panes had closed, and the next pass added them back, filling the room's channel with "memory updated" messages. A heavy room could open on its empty state while it paged back past them. An agent is now retired only when no workspace has its pane open ([#1197](https://github.com/mycelium-io/mycelium/pull/1197))
- **The background daemon job earlier versions installed is removed.** The daemon left the CLI, but its launchd job or systemd service did not, and it failed every ten seconds into `~/.mycelium/logs/cc-daemon.log`. The Mac app removes it when it starts, and so does `mycelium install` ([#1198](https://github.com/mycelium-io/mycelium/pull/1198))
- **A task's Discussion has one layout** on its page, in a tab and in the memory panel: no box around the composer's box, and the heading, replies and composer line up with the task above them ([#1196](https://github.com/mycelium-io/mycelium/pull/1196), [#1193](https://github.com/mycelium-io/mycelium/pull/1193))

## [3.0.26] - 2026-10-07

Rooms keep files. Add them from the message box, preview them in the conversation, and have agents fetch and add them with `mycelium file`.

### Added
- **File uploads in rooms.** Add files from the message box's + menu, by dragging them onto it or by pasting them, several at a time. Each one uploads as soon as it's added, and the message links them. In the conversation, images show as pictures and other files as cards. A preview window shows images, PDFs, Markdown, CSV tables, code and other text, and plays audio and video, with a Download button for every file. A room takes only files the app can preview, checked against what their name says they are, up to 25 MB each. Images are re-saved on the way in, which removes the location and camera details a photo can carry. Each file is a memory at `uploads/<name>`, so it links like one and shows in the Memory list ([#1190](https://github.com/mycelium-io/mycelium/pull/1190))
- **`mycelium file`** for agents and scripts: `upload`, `download`, `ls`, `show` and `rm`. `download` takes the link as it appears in a message, such as `[[uploads/spec.pdf]]` ([#1190](https://github.com/mycelium-io/mycelium/pull/1190))

### Changed
- **The message format is called Mycelium packets, not L9.** The Network pane's inspector, the code and the contracts use the new name, and the L9 reference page is now Messages. L9 now means only what Mycelium takes from IoC: the Concord and Accord flows and the MPC, GAR and SCR metrics. Stored names are unchanged, so existing transcripts read as before. The wire replay route moves to `/messages/wire` ([#1189](https://github.com/mycelium-io/mycelium/pull/1189))
- **The docs open with what Mycelium does for you,** and the Experimental note moves below the demo video ([#1188](https://github.com/mycelium-io/mycelium/pull/1188))
- **The docs' sentences read in one breath.** Sentences that ran on through commas are rewritten or split, with every fact and link unchanged ([#1187](https://github.com/mycelium-io/mycelium/pull/1187))

## [3.0.25] - 2026-10-06

The docs were rewritten after a blind newcomer read. The engines' settings can now be set from `config.toml`.

### Added
- **Config keys for the engines' settings.** These are `[aligner]` (handle, term check, round timeout, step cap and model timeout), `[synthesizer]` (source), `[worker]` (tools, timeout and turn cap), `[board]` (dependency gate) and `telemetry.otlp_headers`. `config apply` passes them to the backend. You no longer edit `.env`, which `config apply` overwrites ([#1184](https://github.com/mycelium-io/mycelium/pull/1184))

### Changed
- **The docs read in order for someone new.** A "How it works" page follows Quick Start, the walkthrough has an "Add the engines" step and memory comes before engines. Each thing has one name. The Board, Conductor and runner pages are split into concept, how-to and reference pages. Pages that contradicted each other or the code now agree with the code ([#1184](https://github.com/mycelium-io/mycelium/pull/1184), [#1186](https://github.com/mycelium-io/mycelium/pull/1186))
- **The docs say plainly what is open by default**, such as sign-in being off, public A2A cards and the "acting as" picker. They also say what a shared hub needs before others can reach it. There's a "which command when" table and one list of every reply marker ([#1186](https://github.com/mycelium-io/mycelium/pull/1186))
- **The Learn courses use the same words and facts as the docs** ([#1185](https://github.com/mycelium-io/mycelium/pull/1185))
