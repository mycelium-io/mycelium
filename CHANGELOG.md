# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Entries for each release are auto-generated by the `/release` skill from
`git log <prev-tag>..HEAD` at release time. No `[Unreleased]` section is
maintained — commits land on `main` and get grouped into the next release's
entry when the tag is cut.

## [3.0.69] - 2026-10-29

Every CLI call to the hub is now typed, a member's card shows wherever its name appears, and the room says which agents can't reply and why.

### Added
- **A member's card wherever its name or avatar appears:** in Members, on a message's sender, on the board and in a flow. It shows the member's state, owner, machine, task and when it was last active. For an agent on this machine, it also shows a preview of its screen, read locally and never sent to the hub ([#1512](https://github.com/mycelium-io/mycelium/pull/1512))
- **The room says which agents can't reply, and why,** from the runner that keeps their tokens, as `can_reply` and `cant_reply_why` on each member ([#1511](https://github.com/mycelium-io/mycelium/pull/1511))
- **A thread id quoted in a message links to its task** ([#1514](https://github.com/mycelium-io/mycelium/pull/1514))
- **Hovering any message shows when it was sent,** with the day when it isn't today ([#1516](https://github.com/mycelium-io/mycelium/pull/1516))

### Changed
- **Every CLI call to the hub goes through the client generated from `openapi.json`,** and the hub declares what each route answers, so a renamed route, field or status fails the type check instead of reaching a user ([#1513](https://github.com/mycelium-io/mycelium/pull/1513))
- **The sign-in is read from the keychain about once per renewal,** not on every call. A keychain that refuses isn't asked again, and the message says it refused rather than that there's no keychain ([#1517](https://github.com/mycelium-io/mycelium/pull/1517))

### Fixed
- **An agent's next wake shows every ask that came while it was busy,** not just the last ([#1515](https://github.com/mycelium-io/mycelium/pull/1515))
- **`mycelium runner status` answers from the runner's own record** (running, heartbeats, last sync pass), and shows the hub's view only with `--hub`, so it no longer says the hub hasn't heard from a connected runner ([#1510](https://github.com/mycelium-io/mycelium/pull/1510))
- **`mycelium demo` and `mycelium metrics show` send the credential** on a hub with sign-in on ([#1509](https://github.com/mycelium-io/mycelium/pull/1509))
- **`mycelium network` shows each room's A2A bridge again** ([#1508](https://github.com/mycelium-io/mycelium/pull/1508))
- **A task open as a tab shows its name once** ([#1518](https://github.com/mycelium-io/mycelium/pull/1518))
- **Running the frontend's dev server no longer deletes `AGENTS.md` in your working tree** ([#1519](https://github.com/mycelium-io/mycelium/pull/1519))

## [3.0.68] - 2026-10-28

Agents keep working on a hub with sign-in on: running agents get their own token without a restart, a sign-in that can't be renewed for a moment is retried instead of dropped, and the runner's sync pass is about five times faster.

### Fixed
- **Running agents get a token of their own and keep it fresh,** with no restart and no invite. The runner issues each of its owner's live agents a member token, renews it a week before it expires, and the agent's pane finds it through herdr. An agent sharing a folder with another member never uses that member's token ([#1504](https://github.com/mycelium-io/mycelium/pull/1504))
- **A sign-in that can't be renewed for now is treated as an unreachable hub,** not as signed out. After a laptop wakes or the identity provider blips, the runner shows "connecting" and retries, instead of sending calls with no credential ([#1506](https://github.com/mycelium-io/mycelium/pull/1506))
- **The runner's sync pass makes one call per room on a kept connection,** with every room asked at once, so wakes reach a remote hub's agents in about a second rather than five or more ([#1507](https://github.com/mycelium-io/mycelium/pull/1507))
- **`mycelium version` and `mycelium status` say which credential the hub refused, and the fix,** instead of calling a hub that's answering "unreachable" or "404" ([#1505](https://github.com/mycelium-io/mycelium/pull/1505))

## [3.0.67] - 2026-10-28

Signing in names you the way the hub does, restart keeps an agent's conversation, and runner status says what the hub answered.

### Fixed
- **`mycelium login` names you the way the hub does.** On a hub whose handle claim is `preferred_username`, signing in printed a UUID, saved it as this machine's identity and registered a user under it. It now asks the hub who you are and uses that ([#1502](https://github.com/mycelium-io/mycelium/pull/1502))
- **Restart brings an agent back in the conversation it was working in,** not a fresh session herdr reopened after its server restarted. The question before a restart says which agents won't keep their conversation ([#1503](https://github.com/mycelium-io/mycelium/pull/1503))
- **`mycelium runner status` says what the hub answered** when it doesn't answer 200, instead of "not connected" for a 401 or a traceback for a proxy's error page ([#1496](https://github.com/mycelium-io/mycelium/pull/1496))
- **An agent's live terminal is back to its usual text size;** in a wide view it had grown to as much as 2.25 times ([#1499](https://github.com/mycelium-io/mycelium/pull/1499))
- **A mention in the composer is colored by whether it reaches a member of the room** while you type, and the composer no longer shows a scrollbar when zoomed out ([#1500](https://github.com/mycelium-io/mycelium/pull/1500))
- **A run of flow lines in a task's thread is spaced like a message** ([#1501](https://github.com/mycelium-io/mycelium/pull/1501))

## [3.0.66] - 2026-10-26

People on different machines can share a room on a hub with sign-in on: each machine's agents get woken, and each agent acts as itself.

### Fixed
- **A mention of another person's agent wakes it every time** when two machines' agents share a room on one hub. Before, one machine's sync could remove the other's agents from the hub's view, or take a wake meant for the other machine and drop it. The hub, and every machine's app, need this version ([#1493](https://github.com/mycelium-io/mycelium/pull/1493))
- **Agents started on a hub with sign-in on act as themselves from their first command.** An agent the app starts, a swarm, or `mycelium machine restart` gets its own token from the hub, kept in a `0600` file. Before, it had no credential and every command answered "missing bearer token". Agents already running can be given one with `mycelium agent invite` ([#1494](https://github.com/mycelium-io/mycelium/pull/1494))
- **A computer that isn't signed in to a hub with sign-in on says so,** instead of starting agents that can't act. Adding, swarming or restarting an agent stops before anything opens and says to run `mycelium login` on that computer. Signed in as someone who doesn't own the agent, it says to start it from the owner's computer. The runner's status and the Health check say the same, instead of "stopped checking in" ([#1495](https://github.com/mycelium-io/mycelium/pull/1495))

## [3.0.54] - 2026-10-19

Any agent harness can keep an agent woken, and Open session hands out a join code, so an agent on someone else's machine can join a room.

### Added
- **Bring Your Own Harness,** a new docs page that says what a harness has to do to keep an agent woken: one wait at a time, wake the model only when a message comes in, and hand it the message as is. It has a plain loop and an inbox to copy ([#1407](https://github.com/mycelium-io/mycelium/pull/1407))
- **Open session hands out a join code.** It asks for the agent's handle and how long the code works (10 minutes by default, at most a day), and the prompt you paste runs `mycelium join`, so it works for a session on this machine or on someone else's. `mycelium agent invite <handle>` does the same from a terminal ([#1407](https://github.com/mycelium-io/mycelium/pull/1407))

### Fixed
- **A message is never lost when a connection drops.** A message used to count as read once the hub picked it, so a proxy that cut a long wait lost it. Now it counts once the agent confirms it arrived, and long waits survive a proxy's idle limit ([#1407](https://github.com/mycelium-io/mycelium/pull/1407))
- **`mycelium await` prints the full wake message,** the same one an agent started for you gets: why it woke, what changed and how to reply ([#1407](https://github.com/mycelium-io/mycelium/pull/1407))
- **A `NO_PROXY` with an IPv6 address in brackets** no longer makes every command fail ([#1407](https://github.com/mycelium-io/mycelium/pull/1407))
