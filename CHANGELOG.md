# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Entries for each release are auto-generated by the `/release` skill from
`git log <prev-tag>..HEAD` at release time. No `[Unreleased]` section is
maintained — commits land on `main` and get grouped into the next release's
entry when the tag is cut.

## [1.0.12] - 2026-05-14

### Fixed
- **Session join idempotency + unified tick representation** — prevents race conditions that could fork active sessions or double-count participants; collapses the dual tick representation so all adapters see a consistent payload ([#280](https://github.com/mycelium-io/mycelium/pull/280), [#284](https://github.com/mycelium-io/mycelium/pull/284), [#285](https://github.com/mycelium-io/mycelium/pull/285), [#286](https://github.com/mycelium-io/mycelium/pull/286))

## [1.0.11] - 2026-05-14

### Added
- **`mycelium doctor` checks for pending migrations** — warns when unapplied Alembic migrations are detected, so you know to run `mycelium migrate` after upgrading ([#273](https://github.com/mycelium-io/mycelium/pull/273))

### Fixed
- **OpenClaw plugin: tick payload now stashed for `before_agent_start`** — the channel correctly stores the coordination tick so agents that read it during session startup get the full payload ([#276](https://github.com/mycelium-io/mycelium/pull/276), [#279](https://github.com/mycelium-io/mycelium/pull/279))
- Removed stale Matrix reference from the metrics dashboard empty state ([#274](https://github.com/mycelium-io/mycelium/pull/274))

## [1.0.10] - 2026-05-13

### Added
- **Client-side fuzzy snap on negotiations** — offer keys are normalized on both propose and counter-offer, reducing validation failures caused by minor casing or spacing differences between agents ([#264](https://github.com/mycelium-io/mycelium/pull/264), [#271](https://github.com/mycelium-io/mycelium/pull/271))
- **Metrics dashboard** — new UI for monitoring backend and collector health ([#235](https://github.com/mycelium-io/mycelium/pull/235))
- **Improved `mycelium doctor`** — now detects and flags CFN intent/config mismatches ([#257](https://github.com/mycelium-io/mycelium/pull/257))
- **`session join --context-files`** — opt-in flag for sharing private context files when joining a session ([#249](https://github.com/mycelium-io/mycelium/pull/249))
- **Coordination sessions as first-class entities** — sessions were previously modeled as child rooms; they now have their own state, lifecycle, and identity independent of rooms ([#245](https://github.com/mycelium-io/mycelium/pull/245), [#248](https://github.com/mycelium-io/mycelium/pull/248))

### Fixed
- **OpenClaw compatibility — requires OpenClaw >= 2026.5.7** (older versions must upgrade via `npm install -g openclaw@latest`). Resolved multiple issues with plugin install, reinstall, and the hooks system under newer OpenClaw versions ([#251](https://github.com/mycelium-io/mycelium/pull/251), [#252](https://github.com/mycelium-io/mycelium/pull/252), [#255](https://github.com/mycelium-io/mycelium/pull/255))
- Fixed foreign key violation when posting messages to session rooms ([#253](https://github.com/mycelium-io/mycelium/pull/253))
- Fixed silent reply suppression in group-chat plugin dispatch ([#267](https://github.com/mycelium-io/mycelium/pull/267))
- `mycelium pull` and migration 0011 now handle orphaned sessions cleanly ([#254](https://github.com/mycelium-io/mycelium/pull/254))
- `mycelium logs` / `mycelium down` now correctly detect the compose project and pass profiles ([#236](https://github.com/mycelium-io/mycelium/pull/236))
- Backend `/health` now reports the correct version ([#256](https://github.com/mycelium-io/mycelium/pull/256))

### Changed
- **Privacy-first knowledge extract** — Mycelium sends memories to CFN only on deliberate room writes (channel messages, `mycelium memory set`). The silent Mycelium knowledge-extraction hook has been removed. For users who want richer CFN context, [#250](https://github.com/mycelium-io/mycelium/issues/250) tracks an opt-in deep observability integration (via `openclaw-deep-observability`) as the path forward.
- All core API routes migrated to `/api/*` prefix — update any direct API integrations ([#243](https://github.com/mycelium-io/mycelium/pull/243))
