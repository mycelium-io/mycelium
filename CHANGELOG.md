# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Entries for each release are auto-generated by the `/release` skill from
`git log <prev-tag>..HEAD` at release time. No `[Unreleased]` section is
maintained — commits land on `main` and get grouped into the next release's
entry when the tag is cut.

## [3.0.0] - 2026-08-20

> **BREAKING: full SLIM-native rewrite.** Coordination no longer runs through
> the Go `ioc-cfn-svc` / CFN management plane — rooms are now durable AGNTCY
> SLIM group channels, memory is local markdown + a JSONL search index (no
> database, no migration), and negotiation is mediated by a first-party
> engine, the aligner. `openclaw` and `hermes` adapters and the litellm brain
> are removed.

### Added
- **SLIM-native rooms + L9 coordination** — each room is one MLS-encrypted SLIM group channel; coordination messages carry additive IOC L9 envelopes (`exchange`, `commit:converged|resolved|rejected`, `knowledge`) ([#417](https://github.com/mycelium-io/mycelium/pull/417), [#420](https://github.com/mycelium-io/mycelium/pull/420), [#421](https://github.com/mycelium-io/mycelium/pull/421), [#425](https://github.com/mycelium-io/mycelium/pull/425))
- **No-database memory store** — memories are markdown + YAML frontmatter under `.mycelium/rooms/{room}/`, indexed by a local fastembed/ONNX embedding index, no external service ([#419](https://github.com/mycelium-io/mycelium/pull/419))
- **The aligner** — a real NEGMAS Stacked Alternating Offers mediator with a persistent Pi-brain session; NEGMAS owns termination, so a summon stops the instant agents agree instead of looping to a step cap ([#426](https://github.com/mycelium-io/mycelium/pull/426), [#682](https://github.com/mycelium-io/mycelium/pull/682), [#680](https://github.com/mycelium-io/mycelium/pull/680), [#679](https://github.com/mycelium-io/mycelium/pull/679), [#681](https://github.com/mycelium-io/mycelium/pull/681))
- **Plan compilation on consensus** — converged terms compile into a shared `plan/tasks.md` checklist with `@handle` owners before `await` returns
- **Server-held participation** — `mycelium await`/`respond` let a turn-based agent (Claude Code, a subagent, a shell) coordinate with two stateless HTTP calls; membership and a durable transcript cursor live on the backend, so a tick is never missed between turns ([#422](https://github.com/mycelium-io/mycelium/pull/422), [#423](https://github.com/mycelium-io/mycelium/pull/423))
- **Durable inbox** — missed point-to-point messages re-serve on rejoin, since SLIM has no offline replay ([#428](https://github.com/mycelium-io/mycelium/pull/428), [#429](https://github.com/mycelium-io/mycelium/pull/429))
- **Three-tier SLIM channel identity** — `psk` (default, zero infra), `signerjwt` (self-signed per-member MLS credentials), and `spire` (SPIRE-attested JWT-SVIDs) ([#476](https://github.com/mycelium-io/mycelium/pull/476), [#579](https://github.com/mycelium-io/mycelium/pull/579), [#588](https://github.com/mycelium-io/mycelium/pull/588), [#589](https://github.com/mycelium-io/mycelium/pull/589), [#590](https://github.com/mycelium-io/mycelium/pull/590))
- **Human + agent OIDC login** and an HTTP-API JWT gate, both off by default ([#561](https://github.com/mycelium-io/mycelium/pull/561), [#563](https://github.com/mycelium-io/mycelium/pull/563), [#564](https://github.com/mycelium-io/mycelium/pull/564), [#606](https://github.com/mycelium-io/mycelium/pull/606))
- **Server-side custodial MLS sessions** — one genuine MLS member per `(room, actor)` under an identity tier, with cryptographic attribution and no re-invite across a restart ([#666](https://github.com/mycelium-io/mycelium/pull/666))
- **Memory linking** — `myc://key` / `[[key]]` wikilinks, backlinks, and opt-in `![[key]]` transclusion ([#611](https://github.com/mycelium-io/mycelium/pull/611))
- **Skills store** — skills are memories under a room's `skills/` namespace, with `mycelium skill` and composer `/` autocomplete ([#617](https://github.com/mycelium-io/mycelium/pull/617), [#618](https://github.com/mycelium-io/mycelium/pull/618), [#619](https://github.com/mycelium-io/mycelium/pull/619))
- **Frontend workspace redesign** — command palette, global search, keyboard-first navigation, cross-room notification center, SWR-cached room data, and a full-page memory view ([#467](https://github.com/mycelium-io/mycelium/pull/467), [#572](https://github.com/mycelium-io/mycelium/pull/572), [#573](https://github.com/mycelium-io/mycelium/pull/573), [#574](https://github.com/mycelium-io/mycelium/pull/574), [#537](https://github.com/mycelium-io/mycelium/pull/537), [#627](https://github.com/mycelium-io/mycelium/pull/627), [#677](https://github.com/mycelium-io/mycelium/pull/677))

### Changed
- **Cold-spawn daemon replaced by resident await loops** — `mycelium await --loop --exec` keeps an agent's own session woken between turns instead of cold-spawning a fresh process per mention, preserving context ([#526](https://github.com/mycelium-io/mycelium/pull/526))
- **Pi is the only cognition runtime** — litellm removed; the aligner brain, plan compiler, and health probe all shell out to `pi` ([#445](https://github.com/mycelium-io/mycelium/pull/445))
- **`await` routes through a durable per-handle delivery cursor**, fixing missed replies across reconnects ([#649](https://github.com/mycelium-io/mycelium/pull/649))
- **`respond`/`reply` honors owner/`allow_from` delegation** ([#659](https://github.com/mycelium-io/mycelium/pull/659))

### Removed
- **The database.** No Postgres, no pgvector, no Alembic migrations — state is markdown files on the hub plus a local embedding index, so this release has no `mycelium migrate` step ([#419](https://github.com/mycelium-io/mycelium/pull/419))
- **CFN/CognitiveEngine knowledge surface and the Go `ioc-cfn-svc` dependency** — coordination runs entirely over SLIM + L9 now ([#417](https://github.com/mycelium-io/mycelium/pull/417))
- **`openclaw` and `hermes` adapters** — unsupported after the SLIM-native cutover; their packages are deleted, not deprecated ([#503](https://github.com/mycelium-io/mycelium/pull/503))

## [1.1.0] - 2026-05-27

### Added
- **Agent primitive** — define agents within a room and invoke them by handle ([#277](https://github.com/mycelium-io/mycelium/pull/277))
  - `mycelium agent {add,ls,show,invoke,rm}` — register an agent as a manifest + notes entry in the room
  - `mycelium daemon` — persistent SSE subscriber that dispatches `@handle` mentions to `claude -p` spawns with the agent's system prompt and identity preamble
  - `mycelium adapter add claude-code --step=daemon` — installs the launchd/systemd daemon unit; `mycelium doctor` reports daemon health
  - **Consensus → plan compiler** — negotiations compile their agreement into the room's shared `plan/tasks.md` checklist; the workflow is now `join → negotiate → plan → work`
  - **Integrations system** — adapters are unified under [`mycelium-cli/src/mycelium/integrations/`](https://github.com/mycelium-io/mycelium/tree/main/mycelium-cli/src/mycelium/integrations), one package per agent framework (dispatch + install colocated). Each framework implements a defined contract, making it straightforward to add support for Hermes, Codex, Cursor, and others.
- **Plan/todo namespace** — a plan is a shared markdown todo list for multi-agent tasks ([#292](https://github.com/mycelium-io/mycelium/pull/292))
  - `mycelium plan {ls,show,set,rm}` and `mycelium plan task {add,done,undo}` — CLI CRUD over `.mycelium/rooms/{room}/plan/`
  - PLAN tab in the frontend with add-task input and interactive checkboxes
  - `plan_open_tasks` injected into every CFN coordination tick on both delivery paths (CLI + OpenClaw plugin)
- **Containerized metrics collector** — OTLP collector now runs as a compose service ([#300](https://github.com/mycelium-io/mycelium/pull/300))
  - Spoke collectors forward to hub via agent-to-gateway OTLP; cross-host spoke sites table in the overview
  - `mycelium metrics traces` viewer for OTel span events with per-room slicing for coordination, knowledge, and cost
  - `mycelium metrics stop` command; collector data dir consolidated under `$MYCELIUM_DATA_DIR/metrics/`
- **`runtime.frontend_port`** — configure the frontend host port in `config.toml`; `mycelium config apply` writes `MYCELIUM_UI_PORT` to `.env` ([#325](https://github.com/mycelium-io/mycelium/pull/325))
- **`mycelium ui open`** — auto-starts the frontend container if it isn't running ([#302](https://github.com/mycelium-io/mycelium/pull/302))

### Fixed
- **Room stream live updates** — Next.js proxy was buffering SSE; replaced with a Route Handler that pipes chunks immediately, and disabled gzip compression that was blocking flush ([#330](https://github.com/mycelium-io/mycelium/pull/330))
- **Upgrade refreshes compose template** — `mycelium upgrade` now copies the embedded `compose.yml` template to `~/.mycelium/docker/` so port mappings and new services stay in sync ([#328](https://github.com/mycelium-io/mycelium/pull/328))
- **Cloud installs: same-origin proxy** — Next.js now proxies all `/api/*` traffic to the backend internally; no need to expose backend port publicly ([#327](https://github.com/mycelium-io/mycelium/pull/327))
- **`mycelium agent add` on root-owned `~/.mycelium`** — CLI now detects root ownership and exits with `chown` guidance instead of a cryptic permission error ([#329](https://github.com/mycelium-io/mycelium/pull/329))
- **OpenClaw plugin: per-agent dispatch chain + timeout** — dispatches serialized per agent (queue depth ≤ 1); 120s timeout prevents permanent wedge ([#294](https://github.com/mycelium-io/mycelium/pull/294))
- **node-svc async calls** — bumps CFN node-svc to resolve async call issues; adds unit test coverage ([#293](https://github.com/mycelium-io/mycelium/pull/293))
- Faithful `.env` materialisation — DB URL, image tag, and all ports now written correctly by `config apply` ([#307](https://github.com/mycelium-io/mycelium/pull/307))
