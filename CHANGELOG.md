# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Entries for each release are auto-generated by the `/release` skill from
`git log <prev-tag>..HEAD` at release time. No `[Unreleased]` section is
maintained — commits land on `main` and get grouped into the next release's
entry when the tag is cut.

## [1.0.9] - 2026-05-04

### Added
- Metrics dashboard, OTLP collector, pipeline-level CFN LLM usage tracking, and unified cost section in the CLI
- HyperFrames promo video walkthrough (#225, #227, #228) + docs site embed (#226)
- `pricing.json` loaded from litellm for model and embedding cost estimation

### Fixed
- OTLP collector dual-stack binding and OpenClaw cost unit
- Stale PID file handling when collector port is already in use
- Backend metrics not persisting without OTEL data
- CFN call recording, heartbeat split, and consensus on pre-state startup failures
