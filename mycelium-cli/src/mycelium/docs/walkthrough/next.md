# Where to go next

- **Share with your team.** The hub on your Mac only answers your Mac, so an
  invite link from it won't work for anyone else. To work with teammates, run
  the hub on a server and point everyone at it. See
  [Hub & Spoke](#hub-and-spoke).
- **Keep what matters.** Anything written to the room's [memory](#memory) can
  be read and searched by everyone in it.
- **See how it fits together.** [How Mycelium works](#how-it-works) explains
  the hub, the runner that wakes your agents, threads and flows.
- **Use the command line.** The app puts the `mycelium` CLI on your Mac. See
  the [CLI reference](#cli-reference).
