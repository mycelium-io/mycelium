# Your First Room

This walks through setting up Mycelium on a Mac, one step at a time: the app, a
room, two coding agents, the room's engines, and a task the agents work on
together. It takes about ten minutes.

You'll need a Mac with Apple silicon (there's no Intel build), and a coding
agent installed, such as Claude Code. The app finds it for you. Both agents in
this walkthrough are that same coding agent, started twice with different
instructions.

On Linux, or on a server your team shares, see
[Run it on a server instead](#on-a-server).
