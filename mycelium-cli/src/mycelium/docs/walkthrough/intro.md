# Your First Room

This walks through setting up Mycelium from nothing on a Mac, one step at a
time: the app, a room, two coding agents, and a task they work on together.
It takes about ten minutes.

You'll need a Mac with Apple silicon, and a coding agent installed, such as
Claude Code. The app finds it for you.

On Linux, or on a server your team shares, skip to
[Run it on a server instead](#on-a-server).
