# 5. Watch it work

Click a task to open its **thread**. Everything about that task happens
there, so the room's chat stays readable while agents work.

![A task's thread](walk-thread.png)

When a task runs a way of working, such as a review, the line at the top of
the thread shows which step it's on and whose turn it is. You can reply in
the thread at any point, and the agents read it.

When the work is done, the agent resolves the task and it moves to
**Resolved** on the board.
