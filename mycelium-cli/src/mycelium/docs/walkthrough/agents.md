# 3. Add your agents

Open **Members** and press **Add**, or pick **Add an agent to this room**.
Choose **Your machine**, then:

1. Start from a role, such as **implementer**. It fills in how the agent
   should work, which you can edit.
2. Give it a handle, such as `builder`. That's how the room mentions it.
3. Check the agent CLI and the folder it works in.
4. Press **Add**.

![Adding a coding agent from a role](walk-add-agent.png)

The agent starts in a terminal session on your Mac, already in the room, and
shows up under **Members**. Add a second one the same way, from the
**reviewer** role, so one can check the other's work.

To watch an agent or type to it directly, choose **Agents terminal** in the
menu bar.
