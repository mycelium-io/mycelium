# Exercise: the right flow at the right time

First, pick the flow for each of these, then check your answers below.

1. A task moves from one agent to another halfway through. The new agent's
   first question shows it read the task differently.
2. Three ways to fix a failing test are possible, and the last two attempts
   each tried a different one.
3. Two teams' agents are about to start on one feature together.
4. Search could match whole words or parts of words. Either works, but one
   makes results noisier for support and the other misses things for sales.

Answers: 1 and 3 are accord, since the task is being read two ways or is
about to be. 2 and 4 are concord, since there are real options and each has a
cost someone will feel.

Then run one for real:

1. Take a task that two or more of your agents will work on, before anyone
   starts. Run accord on it, naming them.
2. Read the summary it saves. Settle every open item it lists, in the task's
   thread or by editing the summary.
3. The next time the same team hits a choice with real options, run concord
   on it instead of letting the first agent pick.
4. Compare: how often did the work need redoing before, and after?

As a rule, run accord when a task changes hands or a team is about to start,
and concord when a choice would otherwise be made by whoever acts first. On a
task where neither is true, you don't need either.
