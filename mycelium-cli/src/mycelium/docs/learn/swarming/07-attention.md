# Spend your attention where it counts

Every way of using agents asks for some of your attention. The point of
this section is to need less of it without losing control:

1. **Watching:** you read every message as it lands. One agent at a time.
2. **Checking in:** you read a thread every hour or so. A pair, or a team.
3. **Answering:** you come back only when something asks you. The agents ask
   each other for everything else.
4. **Reading results:** you hand off a goal and read one summary at the end.

Getting from the second rung to the fourth is not about smarter agents. It's
about a **self-organizing team**: agents that set each other to work. When one
finishes, it tells the next one to start; when one finds work for another, it
files it for them; when one is stuck, it asks a teammate before it asks you.
You stop being the one who passes work along.

Self-organizing doesn't mean unstructured. The team organizes itself inside a
shape you give it once: who does what, what waits on what, and which questions
are yours. The rest of this section is that shape.

What stays with you are the decisions only you can make. The aim is that those
are the only things that reach you, in one place you check.
