# Watch and steer

The terminal you started it from shows the conversation as it happens,
across the task and every part, with long messages cut short and the final
result printed in full. Press Ctrl-C to stop watching; the swarm keeps going.

In the app, the parent task shows its parts as child rows, each with its own
thread. To steer:

- **Before the split lands**, answer in the parent thread if the members'
  offers miss the point. The lead reads it before splitting.
- **On a part**, write in that part's thread. Its builder and its reviewer
  both read it.
- **At the end**, read the lead's combined result in the parent thread before
  you merge anything.
