# Exercise: a team against a pair, then hands off

Take a real task with three clear parts.

1. Write it the way lesson 3 shows, with the parts, what done means and the
   limits.
2. Swarm it with three members and `--worktree`.
3. Note how long it takes and how much of the combined result you'd merge as
   is.
4. Next time a similar task comes up, give it to a pair instead and compare.

Then try the hands-off version. Give your PM the next goal with parts. Add the
four lines from "Lay out work that hands itself off" to every agent's brief.
Check only Needs you until the summary lands. Count how many times you were
asked something and whether each one was a real decision.

As a rule, swarm a task that has parts and give a task without parts to a
pair. Work that has to happen in order is best laid out as a chain that hands
itself off. After a few runs you'll be able to tell which is which from the
task's first line.
