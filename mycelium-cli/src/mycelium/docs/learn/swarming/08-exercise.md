# Exercise: a team against a pair

Take a real task with three clear parts.

1. Write it the way lesson 3 shows: the parts, what done means, the limits.
2. Swarm it with three members and `--worktree`.
3. Note how long it takes, and how much of the combined result you'd merge
   as is.
4. Next time a similar task comes up, give it to a pair instead, and compare.

Swarm what has parts, pair what doesn't. After a few runs you'll tell them
apart from the task's first line.
