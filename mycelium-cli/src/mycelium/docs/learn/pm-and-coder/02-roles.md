# Who does what

- **The PM** holds the task. It writes what done means as a short list of
  checks. It hands the work to the coder one piece at a time and reviews each
  piece against the list. When a piece falls short, it says exactly what's
  missing. It doesn't write code.
- **The coder** does the work in its own checkout and answers the PM's review.
- **You** set the goal and check in every hour or so. You answer when the PM
  asks something it can't decide.

All three of you work in the same place, the task's thread. Everything the pair
says about the task is there in order, so catching up means reading one thread.
