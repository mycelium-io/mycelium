# Start a session

File the task for the coder:

```bash
mycelium board new "Add a gift message to orders" --assign @coder
```

Or type it in the room's chat: `/task Add a gift message to orders @coder`.

Then open the task's thread and hand it to the PM:

> @pm this is yours. Write the checks first, then hand it to @coder.

From here the PM posts its checks, the coder starts on the first piece, and
the review loop begins. You can leave.
