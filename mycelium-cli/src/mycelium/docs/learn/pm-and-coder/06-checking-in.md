# Checking in

Come back every hour or so and open the task's thread. Read it top to bottom,
looking at three things:

- **The checks** at the top. Are they still the right ones?
- **The reviews.** Is each one specific? "Looks good" is a warning sign.
- **Questions for you.** The PM asks in the thread and waits.

If it's going well, leave it. If something needs a nudge, say so in the thread.
Both agents read it.
