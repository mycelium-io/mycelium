# Exercise: your first two-hour run

Pick a real task you'd normally spend an afternoon on: a small feature, a
bug with a clear reproduction, a refactor with tests around it.

1. Give the PM its brief, and bring in the coder.
2. File the task for the coder and hand it to the PM.
3. Leave it for an hour. Don't watch.
4. Come back and read the thread. Note what the PM caught, and what it
   missed.
5. Leave it for another hour, then read it again.

Afterward, change one line in the PM's brief based on what you saw. The brief
gets better every time you run a pair.
