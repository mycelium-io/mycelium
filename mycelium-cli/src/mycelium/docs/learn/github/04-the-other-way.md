# When a task should become an issue

Most tasks never need an issue, because they're done in an hour. Sometimes one
turns out to matter beyond the room. It might be a bug you'll want to find
again or work for someone outside the room. File the issue in GitHub. Then
select the row on the board and press `p` (**Promote → GH**). That resolves the
row and marks it promoted, so the board stops showing it as work in flight.

> It doesn't file the issue for you. You file it yourself. Link it from the
> task if you want the trail.
