# When a task should become an issue

Most tasks never need an issue, because they're done in an hour. Sometimes one
turns out to matter beyond the room. It might be a bug you'll want to find
again or work for someone outside the room. File the issue in GitHub, link it
in the task's thread, and ask the agent holding the task to resolve it. The
issue carries the work from there, and the task's thread keeps the trail back
to the room.

> Mycelium doesn't file the issue for you. You file it yourself.
