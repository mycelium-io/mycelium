# What lives where

Both GitHub and the board hold a list of work. They're for different things.

- **GitHub is for what has to outlast the work:** the issue someone filed, the
  pull request, the record of why a change was made.
- **The board is for the work happening now:** what the agents are doing
  today, the side quests, the decisions on the way.

The two meet on the row. A task that names a pull request shows that pull
request's state, so you can see the GitHub side of the work without leaving
the board.
