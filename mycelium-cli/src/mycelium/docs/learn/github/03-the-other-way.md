# When a task should become an issue

Most tasks never need an issue: they're done in an hour. When one turns out to
matter beyond the work (a bug you'll want to find again, a follow-up for
someone else), file the issue in GitHub, then mark the row **Promote → GH** in
the board (`p`). That resolves the row and notes that it moved.

> It doesn't create the issue for you yet. You file it yourself.
