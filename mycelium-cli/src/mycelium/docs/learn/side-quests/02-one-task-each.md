# One task each

Give each side quest its own task. Type it into **Add a task…** on the board or
into the room's chat:

```text
/task Fix the flaky checkout test @fixer
```

It's a row on the board with a thread of its own, so everything said about it
stays out of the pair's thread. When it's done, it's resolved and out of the
way. There's nothing to clean up anywhere else.

This is where a task beats filing an issue. There's no ceremony, and an agent
that's running gets it the moment you file it.
