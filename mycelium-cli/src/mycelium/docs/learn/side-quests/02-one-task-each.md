# One task each

Give each side quest its own task, from the room's chat:

```
/task Fix the flaky checkout test @fixer
```

It's a row on the board and a thread of its own. When it's done it's resolved
and out of the way, with nothing to clean up anywhere else. This is where
Mycelium's tasks beat filing an issue: there's no ceremony, and the agent has
it the moment you send it.
