# What working like this asks of you

Working this way asks a lot of the person in the middle:

- **Fast creativity.** Trying an idea costs minutes, so try it before you argue
  about it.
- **Strong opinions.** Agents follow the taste they're given. If you don't
  bring yours, you get an average result.
- **Broad, cross-level thinking.** You may move between product questions,
  protocol details and pixel-level design in the same hour.
