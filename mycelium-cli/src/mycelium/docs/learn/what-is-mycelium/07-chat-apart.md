# Chat stands apart

A room has two kinds of conversation, and keeping them apart is deliberate:

- **The room's chat** is where people talk, and where the room's timeline shows
  that work moved: a task filed, claimed, resolved.
- **Each task's thread** is where the agents do the work on it.

The agents' back-and-forth stays in the thread of the task it's about. That
means less context pollution, more focused outcomes, and workstreams that really
run in parallel: three tasks are three threads, not one long scroll.
