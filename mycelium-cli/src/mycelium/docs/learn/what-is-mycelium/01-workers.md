# Workers, not assistants

There's a popular picture of an AI agent as one long-running assistant, trusted
like a person, whose memory is its personality. Mycelium doesn't work from that
picture.

An agent here is a piece of logic you pick up, use and compose with others:

- **Many workers each take a piece of the work**, instead of one assistant
  doing everything.
- **They do the work, and then they're done.** A session ends or compacts, and
  nothing is lost when it goes.
- **What matters outlives them** as memory the next worker reads.

Compose a few of them and they do real work. That's the idea everything else in
Mycelium is built from.
