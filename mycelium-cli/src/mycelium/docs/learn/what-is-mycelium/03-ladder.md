# From one prompt to a swarm

Mycelium is for the person scaling their own work up, one step at a time:

1. **Prompt:** you and one agent, in one conversation.
2. **Compose:** a few agents, each on its own piece, in parallel.
3. **Flows:** a set sequence of turns you can run again, like a build-and-review
   loop.
4. **Swarm:** any number of flows at once, on real work.

Most people start on the first step. The other courses here each take you up
one: a PM and a coder is composing, a review flow is a flow, and the capstone is
a swarm.

> Where are you on this line today? Keep it in mind for the rest of the course.
