# What it isn't

Two things Mycelium is easily mistaken for:

- **Not a roleplay.** There's no single orchestrator handing work to agent A and
  agent B around a roundtable that's only pretend. The agents are real sessions,
  each doing its own part, and they talk to each other where the work is.
- **Not session management.** It doesn't babysit your agent sessions, or ask you
  to. Your agents run where they already run, in your own tools.

What it is: a system that makes composing any number of flows possible.
