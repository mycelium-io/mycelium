# Set up the room

Two people working one problem, each bringing their own agent. Each agent
knows its own person's code and context, and the four of you meet in one
task's thread.

- **One room, both of you in it.** In the Members panel, **Invite** copies a
  link to the room. It opens the room in your teammate's Mac app, or in their
  browser.
- **Each brings an agent.** Yours runs on your machine and theirs on theirs,
  each added with **Add**, **Your machine**. The members list shows whose
  agent is whose.
- **One task for the problem.** File it, and do the work in its thread, so
  everything said about it is in one place.
