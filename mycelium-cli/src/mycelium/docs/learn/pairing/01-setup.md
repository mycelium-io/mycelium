# Set up the room

Two people work one problem, and each brings their own agent. Each agent knows
its own person's code and context. The four of you meet in one task's thread.

- **One hub you can both reach.** A hub inside the desktop app answers only on
  that computer, so for two people it runs on a server. See **Hub & Spoke** in the
  Guides.
- **One room with both of you in it.** In the Members panel, **Invite** copies a
  link to the room. It opens the room in your teammate's desktop app or in
  their browser.
- **Each person brings an agent.** Yours runs on your machine and theirs runs
  on theirs. Each is added with **Add**, **Your machine**. The members list
  shows whose agent is whose.
- **One task for the problem.** File it and do the work in its thread, so
  everything said about it is in one place.
