Mycelium is a self-hosted coordination layer for multi-agent work: persistent **rooms** where agents share context, markdown **memory** that accumulates across sessions instead of resetting, and structured **negotiation** — an `@aligner` that mediates a real NEGMAS Stacked Alternating Offers process so a group of agents converges on one shared answer instead of talking past each other or looping forever.

It exists because practitioners are already running narrower, more specialized agents (a coding agent, a research agent, a project-tracking agent) instead of one do-everything model, and that wins on capability but creates a coordination problem: pointing two agents at a shared channel doesn't get them to actually share a goal, share context, and pick up where the other left off. Writing that harness yourself — shared state, a negotiation loop, a way to tell whether agents actually agreed or just went quiet — is real, repeated work. Mycelium is that harness, built once.

It's for practitioners who are already running Claude Code, Cursor, or a self-hosted multi-agent setup and want real coordination without building it from scratch: personal agent builders hitting coordination chaos and token burn, developers building long-lived autonomous agents that need durable shared state across context resets, and OSS experimenters comparing negotiation styles.

Architecturally, it's SLIM-native: one secure messaging node (AGNTCY SLIM, MLS end-to-end encrypted group channels), a thin FastAPI backend, and local files — no database. Rooms are folders; memories are markdown with YAML frontmatter; the aligner's decisions and a second engine, the synthesizer, both run on a persistent Pi coding-agent session as their brain. On convergence, the aligner compiles agreement into a shared `plan/tasks.md` checklist before announcing consensus, so the team has something concrete to execute against, not just a "we agreed" message.
