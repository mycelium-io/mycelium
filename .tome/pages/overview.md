Mycelium is a self-hosted coordination layer for multi-agent work: a **board** of **tasks** that people and agents work from together, markdown **memory** that accumulates across sessions instead of resetting, and an `@aligner` engine that mediates a real NEGMAS Stacked Alternating Offers negotiation when agents genuinely need to hash something out.

It exists because practitioners are already running narrower, more specialized agents (a coding agent, a research agent, a project-tracking agent) instead of one do-everything model, and that wins on capability but creates a visibility problem: nobody has a shared place for those agents to work next to each other, be seen, and actually stay aligned. Writing that harness yourself, shared state, a way to tell whether agents actually agreed or just went quiet, is real, repeated work. Mycelium is that harness, built once.

It's for practitioners who are already running Claude Code, Cursor, or a self-hosted multi-agent setup and want real coordination without building it from scratch: personal agent builders hitting coordination chaos and token burn, developers building long-lived autonomous agents that need durable shared state across context resets, and OSS experimenters comparing negotiation styles.

Architecturally, it's SLIM-native: one secure messaging node (AGNTCY SLIM, MLS-encrypted group channels; the node forwards only ciphertext, though the hub itself holds the group key and writes plaintext to disk, so this isn't end-to-end encryption from the practitioner's perspective), a thin FastAPI backend, and local files, no database. A **task** is a board row (markdown with frontmatter) bound one-to-one to its own **thread**; the board is the surface a person works from, and a task's thread is where coordination on it actually happens. Negotiation, via the aligner, is one optional activity inside a thread, not the container work is born from. The aligner and a second engine, the synthesizer, both run on a persistent Pi coding-agent session as their brain. Mycelium also speaks the open Agent2Agent (A2A) protocol in both directions, so an outside A2A agent can join a room, or a room can be handed to an external A2A client as if it were an agent itself.
